How to keep score in pickleball

This guide covers doubles side-out scoring, singles, rally scoring, and the mistakes people make most often.

The three-number call

In doubles, the server calls three numbers before every serve: serving team's score – receiving team's score – server number. For example, “4-2-1” means the serving team has 4 points, the receivers have 2, and it is the first server's turn.

Why the game starts at 0-0-2

To offset the advantage of serving first, the team that starts serving gets only one server in its first turn. The game therefore starts at 0-0-2, as if the first server had already lost the serve. When that team loses a rally, it is a side out and the other team serves at server 1.

Server 1, server 2 and side outs

  • Only the serving team can score a point.
  • If the serving team wins the rally, it scores, and the server switches sides with their partner and serves again.
  • If server 1 loses the rally, server 2 serves next, with no point scored.
  • If server 2 loses the rally, it is a side out, and the other team serves starting with its server 1.

Which side do you serve from?

When the serving team's score is even, the player who started on the right serves from the right. When it is odd, they serve from the left. TapCourt shows “Serve from right” or “Serve from left” on the server's side of the scoreboard, so nobody has to work it out.

Singles

Singles has no server number. The call has two numbers, the server's score then the receiver's, and each side out passes the serve straight to the opponent.

Rally scoring (2026)

USA Pickleball allows rally scoring as a provisional format: a point is scored on every rally, whoever served, and the winner of the rally serves next. Since 2026 there is no “freeze” at game point, so the receiving team can also win the final point. Games usually go to 15 or 21, win by 2.
